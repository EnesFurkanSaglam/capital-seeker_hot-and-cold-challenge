# Başkent Tahmin Oyunu

Bu proje, dünya ülkelerinin başkentlerini tahmin etmeye dayalı interaktif bir web oyunudur.

## Özellikler

- Dünya haritası üzerinde interaktif ülke seçimi
- Başkent tahmin sistemi
- Can sistemi (5 can ile başlama)
- Görsel geri bildirimler
- Kullanıcı dostu arayüz

## Nasıl Oynanır

1. Oyun başladığında 5 canınız olacak
2. Harita üzerinde bir ülke seçin
3. Seçtiğiniz ülkenin başkentini tahmin edin
4. Doğru tahmin yaparsanız puan kazanırsınız
5. Yanlış tahmin yaparsanız bir can kaybedersiniz
6. Canlarınız bitene kadar oyuna devam edebilirsiniz

## Teknolojiler

- HTML5
- CSS3
- JavaScript
- SVG Harita
- Font Awesome ikonları

## Kurulum

1. Projeyi klonlayın:
```bash
git clone [repo-url]
```

2. `index.html` dosyasını bir web tarayıcısında açın


# Capital Guessing Game

This project is an interactive web game based on guessing the capitals of world countries.

## Features

- Interactive country selection on world map
- Capital guessing system
- Life system (starting with 5 lives)
- Visual feedback
- User-friendly interface

## How to Play

1. You will start with 5 lives
2. Select a country on the map
3. Guess the capital of the selected country
4. You earn points for correct guesses
5. You lose one life for incorrect guesses
6. You can continue playing until you run out of lives

## Technologies

- HTML5
- CSS3
- JavaScript
- SVG Map
- Font Awesome icons

## Installation

1. Clone the project:
```bash
git clone [repo-url]
```

2. Open `index.html` in a web browser
